# ENVIRONMENT v1 — the world module map
### Where every 3D module lives, and how the world fits together. Canon, 2026-08-11.
**Why this file exists:** M1/M1.1 built mechanics on a placeholder blockout (floating platforms, a shared plaza belt, one crate). This file replaces that blockout with the reference game's actual world structure, verified from the user's own first-hand playthrough screenshots (`evidence/user-playthrough-2026-08-10/`, tags **[US-1…US-4]**) cross-checked against teardown frames [FRAME-nn] and transcripts [VIDEO-nn]. Flow beats still live in `sports-card-farm-player-flow-v1.md` (v1.2); this file owns PLACE — what stands where.
**Build note:** the world is generated by WorldService at runtime (Workspace is deliberately NOT Argon-mapped). An environment rebuild = a WorldService rewrite, not a Studio edit. Scale is relative, not stud-exact — module placement, adjacency, and walkability are canon; exact dimensions are the builder's judgment judged in playtest.

## E0 · World topology
1. One island world. **Center: the Plaza hub.** Ringed by **player bases**, one per player, assigned on join with an owner label ("X's plot"). [US-1, US-3, FRAME-17]
2. A single **arrowed road circuit** (navy strip, white chevrons, low brick guard walls in places) loops the Plaza and passes every base's front edge. [US-2, US-4, FRAME-17]
3. Top-bar teleports **Plaza / Base / Sell** (Sell = the Plaza Sell stall). [US-1, FRAME-04]
4. **Everything is connected and walkable — no gaps, no void jumps.** Base platform, walkway, road, and Plaza form one continuous surface. (Kill-list: the current blockout's floating-platform gap that makes the plot unreachable [US-6 = scf-02 bug shot].)

## E1 · The player base (everything in this section is PER BASE — each player has their own full set)
Rectangular light-stud platform, raised one step above the road, **yellow trim** on the front edge, **wooden fence** along the back and sides, red walkway strip along the front connecting to the road. [US-3, US-4, US-2]

**Zone A — spawn machine (front-left of the base).** [US-2, FRAME-04/05]
5. **Brick spawn structure**: a brown-brick machine wall with a **dark doorway**. The pack belt emerges from the doorway and runs a short straight segment to the **buy window** at its end (one pack at a time, label stack finish · tier · name · price — flow F1).
6. **Spawn Pack podium** (small dark pedestal, green top, pack icon) beside the doorway — the spawn button.
7. **No Pack / Recover Pack ⬡24** green floor pad near the podium (product = monetization milestone; pad + label now).
8. **Conveyor Settings mini-stall** (sign + pad) beside the belt (function = automation milestone).
9. **"More luck! Upgrade Conveyor"** cyan pad (function = conveyor-level milestone; pad + label now).
10. Group/like **billboard** ("JOIN THE GROUP FOR 1.25X CASH!" / like-goal counter) mounted at the spawn structure. [US-2]

**Zone B — plot grid (the base's main area).** [US-3, VIDEO-01]
11. Pedestals stand in **columns interleaved with token lanes**: two pedestal columns, then a lane, repeat (a 10-pedestal starter base = 2 lanes; reference shows 4 lanes on an expanded base). Every pedestal is adjacent to exactly one lane.
12. Token lanes = navy chevron strips running **back → front**, separate from the pack belt. [US-3]
13. A displayed card stands on its pedestal as a big vertical card (name · tier · level · $/Card overhead); **upgrade pad at its foot**; "E Remove" prompt. [FRAME-10]
14. Empty/locked slots show as darker pads (base-expansion affordance, M-later). [US-3, VIDEO-01]

**Zone C — box points (front edge of the base, one per lane).** [US-4, VIDEO-01]

**Zone D — offer pads (front-right).** [US-2, FRAME-04]

## E3 · Pacing & scale rules (the feel)
23. Base → Sell stall walk ≈ 10–15 seconds at default speed: long enough to be a loop beat, short enough to never feel like a chore. [VIDEO-01 sell runs]
24. A base reads as one glanceable unit from the road: cards, lanes, boxes visible without entering (neighbors' progress is the billboard). [US-3, FRAME-17]
25. First-time orientation: a fresh spawn faces the spawn machine; the plot grid is one turn away; the Sell stall is visible/signed from every base's front. [FRAME-04 tutorial arrows]
